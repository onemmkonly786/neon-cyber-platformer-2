NEON CYBER PLATFORMER — STAR SYSTEM + SETTINGS + ANDROID APK UPDATE

THIS UPDATE KEEPS THE EXISTING 50-SECTOR NEON CYBER PLATFORMER.
It does not replace it with a different game.

WHAT'S INCLUDED
- 50 sectors and five boss fights.
- Star ratings: 1 star for clearing a sector, +1 for collecting every coin, +1 for destroying every enemy and hazard. A perfect clear earns 3 stars.
- Boss gates: Level 10 needs 15 stars; Level 20 needs 30; Level 30 needs 45; Level 40 needs 60; Level 50 needs 75.
- Stars and defeated boss progress are saved on the device. Replaying a sector can improve its best star rating, but does not repeatedly add the same stars.
- Enemy defeat reward reduced to 5 credits. Boss defeat reward reduced to 20 credits.
- Settings menu with sound, music, visual effects, difficulty, and touch-button size/opacity/position customization.
- Existing weapons, upgrades, five worlds, particles, sounds, checkpoints, touch controls, and landscape/fullscreen Android build workflow are retained.

UPDATE YOUR EXISTING GITHUB REPOSITORY
1. Extract this ZIP on your Windows computer.
2. Open your existing Neon Cyber Platformer GitHub repository:
   https://github.com/onemmkonly786/neon-cyber-platformer-2
3. Choose Add file > Upload files.
4. Upload ALL files and folders from this ZIP into the ROOT of that same repository.
   Keep the .github/workflows/android.yml folder path exactly as shown.
5. Replace the existing files when GitHub asks. Do not upload this into the separate MOHD-MURAD-KHAN game.
6. Commit the changes.
7. Open Actions > Build Neon Cyber Android APK > Run workflow.
8. When the run turns green, open it and download the artifact named:
   Neon-Cyber-Platformer-APK-Landscape
9. Extract the artifact ZIP. Install app-debug.apk on your Android phone.

The APK build runs in GitHub's cloud; Android Studio is not needed on your Windows 7 computer.
Internet is needed to build/download the APK. Once installed, the game itself works offline.
This is a debug APK for personal testing, not a Play Store release-signed package.

STAR RULES
- Finish a sector: 1 star.
- Collect every coin in that sector: +1 star.
- Destroy every enemy and hazard in that sector: +1 star.
- Therefore, all coins + all enemies/hazards destroyed + sector completed = 3 stars.
- Collect every energy orb as before to unlock the exit.
